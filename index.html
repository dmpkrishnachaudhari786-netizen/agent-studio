    Settings
    
        
    Everything is stored only in this browser (localStorage). Nothing is sent anywhere except the services you configure.
    
      
    

      
    
        
    AI model
    
        
    Pick a current Gemini model. gemini-3.8-flash is the latest generally-available Flash model. (gemini-2.0-* models are shut down.)
    
        
      
    

      
    
        
    Backend (optional)
    
        
    Connect to the FastAPI service to use its authenticated APIs and sandboxed Python. Leave blank to run fully in-browser.

    Direct APIs (offline mode)
    
        
    Used only when no Python server or backend is connected. The key stays in this browser.
    
        
        
        
        
    
          
          
        
    
      
    

      
    
        
    About
    
        
    Agent Studio is the console for the Real Android AI Agent + Web Builder project. Planning follows the project's allow-list: only declared tools with validated arguments are ever produced.
